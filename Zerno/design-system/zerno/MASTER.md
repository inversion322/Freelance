# «Зерно» — дизайн-система кейса Г1 (спешелти-кофе, Москва)

Референсы: palmo.co.in (продукт по центру, крупный заголовок, рукописные пометки со стрелкой, круглые бейджи-факты) и промпт «Soda»
(герой без скролла, стеклянная навигация, 3D-объект следует за курсором, плавающие объекты отталкиваются от курсора,
переключение вкуса: фон меняет цвет, объект крутится на 720° с размытием, спутники схлопываются к центру и разлетаются).
Адаптация: вместо банки — кофейное зерно, вместо вишен — зёрна и листья кофейного дерева, вместо пузырьков — пар, вместо вкусов — обжарки.

## Токены
- Фон героя: радиальный градиент по обжарке — светлая `#8A5A2B/#4E2E14/#1A0F08`, средняя `#6B3A1E/#3A1E10/#140B06`, тёмная `#3A2218/#1E110B/#090504`.
- Крем (акцент, как жёлтый у palmo): `#F3DFAF`, текст на акценте `#2A1608`. Бумага секций: `#F4E9D3`, чернила `#1A0F08`, карамель `#B77A3E`.
- Стекло: `rgba(255,255,255,.08)` + бордер `rgba(255,255,255,.2)` + blur 20px.
- Шрифты: Marck Script (заголовки, рукописные пометки; кириллица), Manrope (текст, навигация). Оба через next/font.
- Кривые: `--ease-out: cubic-bezier(.23,1,.32,1)`; нажатие 160 мс scale(.97); hover только `(hover:hover) and (pointer:fine)`.

## Правила
- Никаких эмодзи-иконок, только SVG. Бренд вымышленный, адрес не указывается, дисклеймер в подвале.
- 3D: процедурное зерно (three), без внешних моделей. Мобильный: зерно остаётся, спутников меньше, без размытия.
- Секции: герой → факты (круглые бейджи) → обжарки → сорта → от вишни до чашки → кофейня и меню → подписка → отзывы → FAQ → подвал.
