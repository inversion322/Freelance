# «Гелий» — дизайн-система кейса Д1 (студия аэродизайна)

Эталон по коду: «Gravity — Digital Studio». Перенесён в Next.js + React Three Fiber без изменения формул физики и порогов стадий.

## Токены
- Фон: фиксированный слой `#bg` с тремя стадиями (`data-stage`): 0 — палитра героя (`--g1/--g2` из выбранной темы), 1 — лайм, 2 — розовый. Переход 1,2 с `cubic-bezier(.65,0,.35,1)`.
- Акцент `#0E2AC5`, орб `radial-gradient(#5175ff → #0e2ac5 → #020b40)`, подвал `#0a0a0a`.
- Шрифты: Raleway (заголовки и текст), JetBrains Mono (метки), Unbounded 800 (словесный знак вместо Space Grotesk — у него нет кириллицы).
- Стекло: `rgba(255,255,255,.2)` + бордер `.4` + blur 24 px + inset-блик.

## Сцена (`components/Field.tsx`)
- 96 шаров (54 на телефоне, 40 при reduced-motion), два InstancedMesh: матовый и стеклянный (transmission). Цвет шара — цвет инстанса, палитра пяти ролей морфится по скроллу: герой → лайм (0.55–1.05) → розовый (1.40–1.95).
- Прогресс = scrollY / vh, сглаживание 0.09 на шаге 60 Гц; физика фиксированным шагом, до 3 шагов за кадр.
- Коллизии: сортировка индексов по x и проход по соседям ближе 1,8 ед. вместо полного перебора пар; 4 подшага.
- Сердце: точки внутри `(x²+y²−1)³ − x²y³ ≤ 0`, радиус шаров в фигуре считается из площади сердца и числа шаров (иначе силуэт сливается).
- Полёт в камеру: вместо прозрачности инстансы уменьшаются к нулю у линзы (per-instance opacity в инстансинге нет).
- Смена палитры пересоздаёт сцену (`key` по цвету) и повторяет влёт шаров.
